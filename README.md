# 🚚 Brazilian E-Commerce Delivery Time Prediction

## 📖 Giới thiệu dự án

Dự án Khoa học Dữ liệu (Data Science) nhằm dự đoán thời gian giao hàng thực tế của các đơn hàng thương mại điện tử tại Brazil, sử dụng bộ dữ liệu Olist. Bài toán giải quyết vấn đề trễ hạn giao hàng, giúp tối ưu hóa vận hành logistics.

## 🎯 Mục tiêu

- Làm sạch và kết hợp (Merge) dữ liệu từ nhiều nguồn (Orders, Customers, Sellers, Geolocation).
- Kỹ nghệ đặc trưng (Feature Engineering): Tính khoảng cách địa lý (Haversine), phân tách dữ liệu thời gian.
- Xây dựng mô hình Machine Learning (Linear Regression, Random Forest, LightGBM) để dự đoán số ngày giao hàng thực tế.

## 🛠️ Công nghệ & Thư viện

- **Ngôn ngữ:** Python
- **Xử lý dữ liệu:** Pandas, Numpy
- **Mô hình hóa:** Scikit-learn, LightGBM
- **Trực quan hóa:** Matplotlib, Seaborn
